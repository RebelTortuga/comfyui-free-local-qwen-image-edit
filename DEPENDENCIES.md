# Dependencies

Install these extensions and their requirements in your ComfyUI environment, then restart ComfyUI and hard-refresh its browser.

| Extension | Upstream | Required node types |
| --- | --- | --- |
| Clean Slate v0.2.0+ | https://github.com/RebelTortuga/comfyui-clean-slate | CleanSlateController, CleanSlateImageMode |
| PromptHistory | https://github.com/dawncreatescode/comfyui-PromptHistory | SelectPromptPairHistory |
| GGUF | https://github.com/city96/ComfyUI-GGUF | UnetLoaderGGUF |
| Essentials | https://github.com/cubiq/ComfyUI_essentials | MaskBlur+ |

Impact Pack is not required by this workflow. Other types below are supplied by a compatible ComfyUI installation; version-specific availability must be checked in your running server.
